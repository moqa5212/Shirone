从零开始，搭建属于自己的个人博客。

Hexo 是一款轻量、快速的静态博客框架。通过简单的配置与命令，就能将 Markdown 文章转换为静态网页，并部署到自己的服务器或 GitHub Pages 上。

本系列将从最基础的环境准备开始，逐步介绍 Hexo 的安装、配置、主题使用、文章编写以及网站部署等内容。即使没有太多建站经验，也可以跟随教程一步步完成自己的博客。

从安装 Node.js、搭建 Hexo 环境，到配置主题、发布文章，再到最终将网站部署上线，希望通过这一系列记录，让每一个步骤都清晰易懂。

愿每个人都能拥有一片属于自己的网络空间。
